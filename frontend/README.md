# Data QA Lab UI

React + TypeScript + Vite + CodeMirror. All runtime assets are local.

`npm ci` then `npm run dev` (API on 127.0.0.1:8000). Or `npm run build`, restart the API and browse http://127.0.0.1:8000. Full Compose startup is documented in the V1 release guide.

ENG/VIE picker, six guided lessons, SQL execution, deterministic grading, hints,
reveal and retained history; pipeline/QA and isolated fault evidence. Credentials
and instructor-only grading fixtures never reach the frontend in Challenge mode.
